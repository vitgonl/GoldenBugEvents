# GoldenBugEvents

## Sobre o projeto

O GoldenBugEvents é um trabalho da faculdade/escola feito com Vue.js. A ideia do projeto é criar um site onde as pessoas possam ver alguns eventos e procurar aqueles que mais lhes interessam.

O site tem uma lista de eventos, uma pesquisa, filtros por categoria e a opção de guardar eventos nos favoritos.

## Tecnologias usadas

- HTML
- CSS
- JavaScript
- Vue.js
- Vite

## O que o site faz

- Mostra vários eventos.
- Permite pesquisar eventos pelo nome.
- Permite filtrar os eventos por categoria.
- Permite ver mais informações sobre os eventos.
- Permite marcar eventos como favoritos.
- Adapta a página para ecrãs mais pequenos.

## Como abrir o projeto

Para executar o projeto, é preciso ter o Node.js instalado.

1. Abrir a pasta do projeto no VS Code.
2. Abrir o terminal.
3. Escrever o comando:

npm install

4. Depois, executar:

npm run dev

5. Abrir no navegador o endereço que aparecer no terminal.

## Organização dos ficheiros

- `App.vue` — é o ficheiro principal da página.
- `Header.vue` — tem o cabeçalho e o menu.
- `SearchBar.vue` — tem a barra de pesquisa.
- `EventCard.vue` — mostra as informações dos eventos.
- `Footer.vue` — tem o rodapé da página.
- `style.css` — contém os estilos do site.
- `main.js` — inicia a aplicação.

## O que aprendemos com Vue.js

Neste trabalho, utilizámos componentes para separar o código e facilitar a organização. Também trabalhámos com props, `ref()` e diretivas como `v-for`, `v-if`, `v-show` e `v-model`, para mostrar informações e permitir a interação com a página.
